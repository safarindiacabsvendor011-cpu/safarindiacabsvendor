# Safari India Cabs Vendor

B2B Taxi and Cab Vendor Management Platform for Safari India Cabs.

## Features
- Vite + React + TypeScript + Tailwind CSS setup
- Express server integration ready
- Vendor management, fleet tracking, and taxi dispatch architecture

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
